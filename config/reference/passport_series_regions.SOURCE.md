# Серия паспорта → код подразделения по региону

Первые две цифры серии паспорта РФ — код региона по ОКАТО (Дагестан — 82),
первые две цифры кода подразделения — номер региона (Дагестан — 05). Чтобы
сверить «код подразделения соответствует серии», нужна эта таблица
(`app/engine/passport.py::check_department_code_region`).

- `series` — первые две цифры серии;
- `department` — допустимые первые две цифры кода подразделения через `;`
  (несколько — бывшие автономные округа и паспорта Крыма/Севастополя 2014 года);
- `region` — для людей.

Серии нет в таблице (новые регионы и т. п.) — сверка не делается, замечания
нет. Составлено по ОКАТО и номерам субъектов РФ, 09.11.2026.
