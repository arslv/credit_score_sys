# БКИ через Спектрум Дату

У заказчика есть кабинет Спектрум Даты с двумя пакетами — это две кнопки в
карточке заявки (`bki.report_types` в правилах, `app/sources/spectrum.py`):

| Кнопка | Пакет | Что внутри |
| --- | --- | --- |
| Обычный | «Кредитный рейтинг» | блок `P.0191.CRR.HIS`: балл 0–999, текущая и максимальная просрочка, число кредитов, средний платёж, лимит, обращения в бюро за 7/14/30 дней, безнадёжный долг |
| Подробный | «Проверка соискателя — Премиум» | тот же кредитный рейтинг и ~30 проверок: ФССП, банкротство, паспорт (недействительные), ИНН, самозанятость, террористы и экстремисты, суды, розыск… |

## Как используем

- Запрос — только по кнопке сотрудника (`BKI_REQUEST_MODE=manual`), каждая
  проверка списывается из пакета.
- Кредитный рейтинг → балл, ПДН и признаки просрочек для правил. Суммы и
  количества у бюро — диапазонами; какую границу брать — `bki.range_bound`
  (по умолчанию верхняя, осторожнее). «Средний платёж» считаем платежом по
  всем действующим кредитам в месяц — проверить на первых настоящих ответах.
- Проверки из подробного пакета пишутся в `bki_bureau_checks` и показываются
  в карточке рядом с нашими с пометкой «БКИ». **В решение не входят** — наши
  проверки (ФССП с капчей, банкротство вручную…) идут как обычно.
- Сырой ответ бюро — в `bki_reports.report_raw.raw`.

## Что осталось (нужны данные из кабинета)

1. Описание API: адрес, авторизация, как заказать отчёт и получить результат →
   HTTP-реализация `SpectrumTransport` и подключение в `app/sources/factory.py`.
2. Идентификаторы двух пакетов → `bki.report_types.*.provider_code` в правилах.
3. Доступ к API (логин/пароль или токен) → `.env` на сервере.
4. Проверить на живом «Подробном» отчёте, что блоки приходят по тем же путям,
   что в описаниях. Разобраны (`BUREAU_BLOCKS` в `app/sources/spectrum.py`):
   ФССП (P.0035 — открытые ИП и долг), банкротство (P.0124), недействительный
   паспорт (P.0308), ИНН (P.0031; если наш ФНС ИНН не нашёл, карточка берёт
   его для поиска на Федресурсе), самозанятый (P.0247), перечень террористов
   (P.0043 — с релевантностью). Остальные блоки пакета, если понадобятся, —
   по их описаниям; блок без описания в карточке не показывается.

Описание API (п. 1) в разделе «Документация» кабинета — только список блоков;
ищем по иконке «ASYNC API» у блока или запрашиваем у менеджера Спектрум Даты.
